Note: Compose's legacy Icons.Filled.GppGood has no "gpp_good" glyph in Material Symbols (checked
the source repository directly - that name doesn't exist there); Material Symbols renamed it to
"verified" (same shield-with-checkmark silhouette), so ic_gpp_good_rounded.xml is sourced from
that glyph instead. Similarly there's no separate "notifications_none" glyph - Material Symbols
folds the outline/filled bell into one glyph via the FILL axis, so ic_notifications_none_rounded.xml
reuses notifications/materialsymbolsrounded but takes the plain (non-fill1) outline variant, the
same way Icons.Filled.NotificationsNone was always just the outline bell next to the filled ones.

Note: apps_24px/apps_fill1_24px were used for ic_nav_apps_* and update_24px/update_fill1_24px
for ic_nav_update_* originally, but Google's own outline/fill1 variants of those two glyphs are
byte-identical at the source (their FILL axis has no visual effect on a dot-grid or clock-arrow
shape), so the selected/unselected nav states never looked different for those two tabs. Swapped
to grid_view, then to download_for_offline for the Updates tab specifically (system_update was
tried in between but read as cluttered at 24dp) - both have distinct outline/fill1 art.

Used for the bottom navigation bar's icon set (dev.cl0ud9.manager.ui.navigation.NavIcon /
ManagerDestination), matching the reference app's Material Symbols Rounded icon style without
depending on that app's own (proprietary-licensed) bundled copies of these same public icons.
The four icons added below extend that same rounded icon family to the app's highest-visibility
non-nav icons (status badges, the manager-update glyph, and every pushed screen's back button) -
each is the "fill1" (solid) variant, matching Compose's Icons.Filled family these replace. The
twelve icons after that extend the family again to the onboarding flow's icon collage and morphing
action button, and the six after that extend it once more to the Settings/Appearance/GitHub-access
rows' badge icons and their shared trailing chevron. The feedback icon added last is the badge for
the Feedback & diagnostics settings row - same fill1-matches-Icons.Filled convention throughout.
